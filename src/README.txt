
Jahreszeiten-Enum

Dieses Projekt demonstriert die Verwendung von Enums in Java, um die Jahreszeiten (Frühling, Sommer, Herbst, Winter) 
zu modellieren. Es enthält Methoden zur Beschreibung der Jahreszeiten und zum Umschalten auf die nächste Jahreszeit.

Features:
- Modellierung der Jahreszeiten mit Enums.
- Beschreibung der Jahreszeiten.
- Umschalten auf die nächste Jahreszeit.

Technologien
- Java
- Enums
- Objektorientierte Programmierung
